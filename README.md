

# YouTube Clone - Backend
 
  Backend API for a youtube clone application built using node.js,express.js,mongoDB and JWT authentication.The backend API provides APIS for user authentication,channel management,video management,comments,likes/dislikes,search and category filtering


# Features

 - User Registration
 - User Login
 - JWT Authentication
 - Password hasing using bcrypt
 - Protected API Routes
 - User / Channel management
 - Create Channel
 - Get Channel details
 - Upload Video
 - Get Videos
 - Get Single Video
 - Search video by title
 - Filter videos by category
 - Like Video
 - Dislike Video
 - Add Comments
 - Get Comments
 - Edit Comment
 - Delete Comment
 - MongoDB database integration
 - API Error Handling
 - CROS Suppourt
 - Database seed data


# Technologies Used
 
 - Node.js
 - Express.js
 - MongoDB
 - Mongoose
 - JSON Web Token (JWT)
 - bcryptjs
 - dontenv
 - cros
 - Javascript ES module
